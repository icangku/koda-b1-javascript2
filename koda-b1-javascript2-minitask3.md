# Minitask 3

## Circumference and Area of a Circle Edition

There is an object method of circle.
It has radius property.
In it there are two functions

- area:

  This function is to find the area of the circle by doing the calculation of area formula, Pi x r x r

- circumference:

  This function is to find the circumference of the circle using this formula, 2 x Pi x r

We call the radius using 'this' to get the property inside of the object method inside of both functions, in this case 'radius' property.

Then we create another function call 'ringkasan' or summary, to call both the methods in the circle object method.
